ESP32 WiFi Bridge

Flash firmware directly from your browser using Web Serial. This bridge forwards encrypted traffic from Ethernet to a Tesla Powerwall over WiFi.

Your browser doesn't support Web Serial. Use Chrome, Edge, or Opera.
Loading version info...

Requirements

  • Chrome, Edge, or Opera browser
  • ESP32-S3-POE-ETH board connected via USB
  • Hold BOOT button while connecting if device doesn't appear

After Flashing

  • Connect to the device's Ethernet port
  • Access the web UI at http://powerwall.local/
  • Configure your Powerwall WiFi credentials
